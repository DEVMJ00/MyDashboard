Linux

  • Création d'une boucle pour agir sur l'intégralité des fichiers d'un dossier 
    for file in .*; do
mv "$file" "${file#.}"
done
  • Liste les fichiers et dossiers dans le répertoire actuel : 
    ls          #affichage simple
ls -l       #affichage détaillé
ls -a       #affichage des fichiers cachés
  • Changer de répertoire : cd
  • Remonter d'un niveau dans l'arborescence : cd ..
  • Ouvrir le répertoire courant das l'explorateur : xdg-open .
  • Affiche le chemin du répertoire actuel : pwd
  • Créer un nouveau dossier : mkdir mon_dossier
  • Créer un fichier vide : touch nom_du_fichier_.extension
  • Copier un fichier : cp fichier1.txt fichier2.txt
  • Copier un dossier : cp -r dossier1 dossier2
  • Supprimer un fichier : rm fichier.txt
  • Supprimer un dossier et son contenu : 
    rm -r dossier   #Supprime tout 
rm -i           #Demande une confirmation avant suppression
  • Déplacer ou renommer un fichier : mv ancien_nom.txt nouveau_nom.txt
  • Affiche le contenu d'un fichier : cat fichier.txt
  • Ouvrir éditeurs de texte en ligne de commande : nano fichier.txt
  • Changer les permissions d'un fichier ou dossier : chmod +x script.sh
  • Rechercher un fichier dans l'arborescence : find /home -name "index.html"

Informations système

  • Afficher les informations sur le système d'exploitation : uname -a
  • Afficher l'espace disque utilisé : df -h
  • Afficher les processus en cours et l'utilisation des ressources : top
  • Afficher l'utilisation de la mémoire : free -h

Installation et gestion des logiciels

  • Mettre à jour la liste des paquets disponibles : sudo apt update
  • Mettre à jour les paquets installés : sudo apt upgrade
  • Installer un logiciel : sudo apt install [nom_paquet]
  • Désinstaller un logiciel : sudo apt remove [nom_paquet]

Gestion des utilisateurs et des permissions

  • Afficher l'utilisateur actuel : whoami
  • Gèrer les permissions et les propriétaires : chmod 755 [script.sh]

Commandes réseau

  • Vérifier la connectivité réseau : ping google.com
  • Afficher les informations réseau: ip a
  • Télécharge un fichier depuis une URL: curl https://example.com

Commandes pour afficher le matériel

  • Liste détaillée du matériel : sudo lshw
  • Liste résumée du matériel : sudo lshw -short
  • Afficher un type particulier de matériel : sudo lshw -class processor
  • Informations sur le processeur : lscpu
  • Informations sur les périphériques de stockage : lsblk
  • Informations détaillées sur les périphériques de stockage : lsblk -f
  • Informations complètes sur le système et le matériel : sudo apt install inxi, puis : inxi -Fxz
  • Rapport détaillé sur le matériel : sudo apt install hwinfo, puis : sudo hwinfo

🐧 Linux / Raspberry Pi

  • Mettre à jour les paquets : sudo apt update && sudo apt upgrade
  • Voir l'espace disque : df -h
  • Voir les processus : top
  • Voir l'adresse IP : hostname -I
  • Redémarrer : sudo reboot
  • Éteindre : sudo shutdown now

Remarques supplémentaires

Pour consulter le manuel d'une commande, utiliser man [nom_commande]. Créer des alias pour des commandes courantes avec alias pour gagner du temps.

🗄️ SQL / Oracle - Cheat Sheet

🔍 Sélection

  • SELECT * FROM table;
  • SELECT col1, col2 FROM table;
  • SELECT DISTINCT colonne FROM table;
  • SELECT COUNT(*) FROM table;
  • SELECT COUNT(DISTINCT colonne) FROM table;

🎯 Filtrer

  • WHERE
  • AND / OR / NOT
  • LIKE '%texte%'
  • IN (...)
  • BETWEEN ... AND ...
  • IS NULL / IS NOT NULL

📊 Trier

  • ORDER BY colonne ASC
  • ORDER BY colonne DESC

📦 Groupement

  • GROUP BY
  • HAVING COUNT(*) > 1

🔗 Jointures

  • INNER JOIN
  • LEFT JOIN
  • RIGHT JOIN
  • FULL OUTER JOIN

📝 Modification

  • INSERT INTO ...
  • UPDATE ... SET ... WHERE ...
  • DELETE FROM ... WHERE ...
  • Toujours vérifier le WHERE avant UPDATE ou DELETE.

💾 Transactions

  • COMMIT;
  • ROLLBACK;
  • SAVEPOINT nom;

🚀 Performance

  • Limiter le SELECT *.
  • Indexer les colonnes filtrées fréquemment.
  • Toujours filtrer avant de joindre.
  • Éviter les fonctions sur les colonnes indexées.
  • Utiliser EXPLAIN PLAN.

⚠️ Bonnes pratiques

  • Tester les UPDATE avec un SELECT.
  • Toujours prévoir un ROLLBACK possible.
  • Utiliser des alias explicites.
  • Commenter les requêtes complexes.
  • Sauvegarder avant les traitements massifs.
